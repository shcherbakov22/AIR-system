# Mentor Workflow

## Mentor Responsibilities

Mentors use the app to manage the working environment and watch students in real time.

## Core Mentor Areas

### Students

Mentors can:

- create students
- edit student details
- change or reset student passwords
- delete student users
- open each student’s progress page

### Task Templates

Mentors manage the task catalog used by schedules and custom timers.

### Schedule Templates

Mentors can maintain schedule-template structures on the admin side.

### Rules

Mentors create and edit the rules students are expected to follow.

### Violations

Mentors can:

- create violations
- review them
- resolve them
- delete them

## Monitor Dashboard

The mentor dashboard is the real-time control room.

It shows:

- one column per student
- active task/session state
- schedule progress
- per-block timing information
- latest screen and camera previews
- open violations

The dashboard also supports:

- fullscreen capture modal
- same-day capture history
- auto-refresh
- browser TTS announcements

## Student Progress Page

The progress page is the mentor’s historical view.

It shows:

- schedule runs
- block completion
- actual start/end timing
- time spent per block
- session history inside runs

## Operational Speech

The mentor dashboard can speak queued announcements such as:

- new violations
- completed task sessions

This is browser-based speech synthesis, not a server-side audio system.
